# Flourish & Bloom

This release keeps your personal planning experience private, local-first, and branded as Flourish & Bloom.

Deploy every file in this folder to GitHub Pages, then open once with `?v=flourish-and-bloom#today`.


## Version 8.1.3
- Fixed Calendar History opening with an independent navigation handler.
- Added the calendar script to offline caching.
- Replaced unsupported instant scrolling for better iPhone compatibility.

Flourish & Bloom 2.0 recovery build: rebuilt home UI from stable v8.1.3 while preserving app logic.


## Flourish & Bloom 9 Interactive Living World
- Time-aware greeting and gentle streak
- Daily mood check-in and monthly mood history
- Australian seasonal garden, time-of-day ambience and daily visitors
- Unlockable featured flowers and habit celebrations
- Optional generated garden sounds (no external audio files)
- Guided journal prompts
- Interactive Memory Tree with locally saved moments

All Flourish & Bloom 9 data is additive and stored separately under `flourishBloom-v9-interactive`. Existing planner data and features are unchanged.


## Flourish & Bloom 10 — Story World
Adds the Reading Corner, Letters to Future You, weekly Garden Snapshots, Achievement Scrapbook and Evening Wrap-up. New feature data is stored separately under `flourishBloom-v10-story-features`; existing planner data is unchanged.
